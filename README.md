# Sistema-de-cadastramento
```text
Sistema-de-cadastramento/
├── sistema/
│    ├── data/ 
│    │   ├── control
│    │   └── dados
│    ├── aluno
│    ├── app
│    ├── back
│    └── disciplina
├── .gitignore
└──  README
```
Esta seria a arquitetura do meu projeto pessoal 
- crie duas classes(aluno / disciplina) elas vão ter a tarefa de criar alunos e disciplinas.
- as informações são adicionadas posteriormente em dicionários ou listas.
- o sistema guarda a informação do aluno com o RM como chave e das disciplinas com o ids , permitindo repetir nomes.
- cada classe tem suas próprias funções.
- o arquivo control vai trabalhar com o Json.
- o arquivo back vai ser a base de operações onde cada função vai ser feita.
- o arquivo app vai ser o visual principal do usuario.
- deixei o json para que você consiga entender como as informações são salvas.
